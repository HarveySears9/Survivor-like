# Survivor-like

A 2D roguelite survivor game inspired by *Vampire Survivors*, built entirely in **Unity (C#)** as a portfolio project.

The goal of this project is to design and implement scalable gameplay systems rather than simply recreate an existing game. Every major mechanic is being developed from scratch with maintainability, extensibility, and clean code in mind.

## Project Goals

This project is intended to demonstrate my skills as a gameplay programmer by building a complete game architecture including:

* Modular weapon and ability systems
* Enemy AI and spawning systems
* Character progression and meta progression
* Save/load functionality
* Upgrade and unlock systems
* UI and gameplay feedback
* Achievement and mission systems
* Boss encounters
* Performance optimisation for large enemy counts

Rather than relying on third-party assets or packages, I aim to implement as many gameplay systems myself to gain a deeper understanding of game development.

## Why I Built This

I started this project to challenge myself with creating a complete game from the ground up while improving my software engineering skills.

Rather than treating it as a small prototype, I'm using it as an opportunity to practice designing reusable systems, refactoring code as the project grows, and solving gameplay programming problems that arise during development.

As the project evolves, I continue to improve existing systems instead of settling for the first working solution, helping me build better habits for professional game development.
